# Mi Portafolio Web

¡Bienvenida/o a mi portafolio personal! Este proyecto reúne mis primeros trabajos como desarrolladora web, estructurado con HTML, personalizado con CSS y controlado mediante Git y GitHub.

## 🛠️ Tecnologías Utilizadas

- **HTML5**: Estructura semántica de la página.
- **CSS3**: Diseños y estilos responsivos.
- **JavaScript**: Lógica e interactividad.
- **Git & GitHub**: Control de versiones y alojamiento del código.

## 🚀 Proyectos Destacados

1. **Calculadora Interactiva**: Aplicación web para cálculos matemáticos en tiempo real.
2. **Lista de Tareas (To-Do)**: Herramienta para gestionar tareas diarias con almacenamiento local.
3. **Portafolio Web Personal**: Página de presentación profesional con secciones de información, contacto y proyectos.
